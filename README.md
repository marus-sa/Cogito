# Cogito · Light Hearts

Cogito — браузерная платформа для учеников, родителей, репетиторов, наставников и команды Light Hearts.

Это не статический макет: Vue-интерфейс работает с Flask API, а данные хранятся в SQLite локально или PostgreSQL на хостинге. После сборки сайт и API запускаются на одном адресе.

## Что уже работает

- регистрация ученика и родителя;
- заявка репетитора с подтверждением администратором;
- приглашение наставников и администраторов только через команду проекта;
- вход через защищённую HTTP-only cookie, без хранения токена в браузере;
- отдельный доступ к занятиям, заданиям, целям, чатам и уведомлениям;
- создание и проверка занятий, домашние задания, учебные цели, сообщения и уведомления;
- очередь заявок репетиторов в разделе «Отчёты» администратора;
- адаптивный интерфейс для компьютера и телефона.

## Локальный запуск

Нужны Node.js 20+ и Python 3.10+.

```bash
cd server
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/python app.py
```

Во втором терминале:

```bash
npm install
npm run dev
```

Для проверки серверной части:

```bash
npm run test:api
```

## Публикация без домена

Проект подготовлен для Render: файл `render.yaml` создаёт веб-сервис и PostgreSQL в Frankfurt. После публикации Render выдаст временный публичный адрес вида `https://cogito-light-hearts.onrender.com`.

1. Создайте бесплатные аккаунты на GitHub и Render.
2. Загрузите этот проект в новый приватный GitHub-репозиторий.
3. В Render выберите **New → Blueprint**, подключите репозиторий и подтвердите ресурсы из `render.yaml`.
4. После завершения сборки откройте выданный адрес и войдите как администратор.

Для стартового наполнения в первой базе создаются демонстрационные учётные записи. Их пароль — `cogito123`. Перед приглашением настоящих пользователей смените пароль администратора и удалите демо-аккаунты через базу.

Бесплатный Web Service Render может засыпать после 15 минут без посетителей, поэтому для постоянной работы проекта лучше перейти на платный тариф. Render поддерживает Flask, Docker и PostgreSQL, а Blueprint связывает сервис с базой автоматически. [Документация Render](https://render.com/docs/your-first-deploy)

## Переменные окружения

| Переменная | Для чего нужна |
| --- | --- |
| `DATABASE_URL` | строка подключения к PostgreSQL; без неё используется локальная SQLite-база |
| `FLASK_ENV=production` | включает защищённую cookie для публичного HTTPS-сайта |
| `PORT` | порт, который задаёт хостинг |

`docker-compose.yml` нужен только для локального запуска с PostgreSQL. Скопируйте `.env.example` в `.env`, укажите свой пароль и запустите `docker compose up --build`.
