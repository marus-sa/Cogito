# Cogito · Light Hearts

Рабочее веб-приложение для учеников, родителей, репетиторов, наставников и администрации. Интерфейс сделан на Vue, сервер — на Python/Flask. Данные хранятся в SQLite локально или PostgreSQL на хостинге.

## Что лежит в проекте

- `src` — интерфейс сайта: страницы, кнопки и оформление;
- `server` — сервер, вход, роли, чаты и база данных;
- `Dockerfile` и `docker-compose.yml` — запуск одной командой;
- `render.yaml` — настройка публикации на Render.

## Запуск через Docker

1. Скопируйте `.env.example` в `.env` и укажите свой пароль для локальной базы.
2. Выполните:

```bash
docker compose up --build
```

Сайт откроется по адресу `http://localhost:5000`.

## Запуск без Docker

Нужны Node.js 20+ и Python 3.10+.

```bash
cd server
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/python app.py
```

Во втором терминале:

```bash
npm install
npm run dev
```

## Публикация

`render.yaml` создаёт на Render веб-сервис и PostgreSQL. В Render нужно задать `ADMIN_EMAIL`, `ADMIN_BOOTSTRAP_PASSWORD` и, для писем, SMTP-переменные из `.env.example`. Секреты не добавляются в GitHub.
