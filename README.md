# Cogito · Light Hearts

Веб-приложение для бесплатных занятий: расписание, задания, чаты, цели и учёт волонтёрских часов. Пять ролей: ученик, родитель, репетитор, наставник и администратор.

## Где находится код

```text
server/
  app.py        запуск сервера и раздача сайта
  accounts.py   регистрация, вход, письма и профиль
  admin.py      доступ администратора, заявки и участники
  study.py      занятия, задания, цели и отчёты
  chat.py       контакты, переписки и уведомления
  common.py     общие проверки, права и сессии
  database.py   таблицы и подключение к базе
  demo.py       тестовые данные, выключены по умолчанию
src/
  main.js       запуск интерфейса
  router.js     адреса страниц и проверка входа
  Layout.vue    общее меню и шапка
  views/        страницы с формами и кнопками
  stores/       загрузка и хранение данных страниц
  components/   общие кнопки, окна и карточки
  styles/       общее оформление и стили главной
  api.js        запросы к серверу
  config.js     роли и меню
  helpers.js    небольшие расчёты и проверка ссылок
```

Начните с создания занятия:
`ScheduleView.vue` → `stores/lessons.js` → `api.js` → `server/study.py` → `database.py`.

В `.vue`-файле `script` содержит действия, `template` — разметку, `style` — оформление. Большие стили главной вынесены в `styles/dashboard.css`. На сервере обычные функции и SQL. Blueprint объединяет обработчики одного файла; `app.py` подключает четыре таких раздела. Других слоёв между запросом и базой нет.

## Запуск без Docker

Нужны Node.js 22.12+ и Python 3.10+. Из корня проекта:

```bash
npm ci
python3 -m venv server/.venv
server/.venv/bin/pip install -r server/requirements.txt
npm run server
```

Во втором терминале: `npm run dev`. Откройте адрес из терминала. В пустой локальной базе первого администратора создают на `/setup-admin`. По умолчанию используется SQLite в `server/data`; тестовые данные включаются только через `COGITO_DEMO_DATA=1`.

## Запуск через Docker

Скопируйте `.env.example` в `.env`, задайте `POSTGRES_PASSWORD`, `ADMIN_EMAIL` и `ADMIN_BOOTSTRAP_PASSWORD` (от 12 символов). Затем:

```bash
docker compose up --build
```

Сайт: `http://localhost:5000`. Compose запускает приложение и PostgreSQL, данные базы сохраняются в отдельном томе.

## Проверки

После установки зависимостей запустите `npm run check`: сборка, клиентские тесты, API и все роли. Серверные тесты используют временные базы, не реальные аккаунты. В `.github/workflows/check.yml` тот же набор проверок и сборка Docker для GitHub.

## Аккаунты и публикация

Роль берётся из базы. Администратор назначает роли, блокирует аккаунты и связывает участников в «Участниках». Родитель видит только данные связанного ребёнка. Выход завершает одну сессию; блокировка и смена роли — все сессии участника.

Для входа с разных устройств нужен один HTTPS-адрес с общей PostgreSQL. В Render задайте `DATABASE_URL`, `APP_URL`, `ADMIN_EMAIL`, `ADMIN_BOOTSTRAP_PASSWORD` и SMTP-настройки из `.env.example`. Пароли, `.env` и файлы базы не загружаются в GitHub.

Новая база и доставка писем пока не настроены. Render Free PostgreSQL действует 30 дней после создания: до истечения срока сохраните или перенесите данные. Бесплатный веб-сервис Render блокирует SMTP-порты 25/465/587; нужен поддерживаемый отправителем порт 2525 с TLS либо доработка отправки через HTTPS. [Ограничения Render](https://render.com/docs/free).
