# Cogito · Light Hearts

Cogito — браузерная платформа для учеников, родителей, репетиторов, наставников и команды Light Hearts.

Это не статический макет: Vue-интерфейс работает с Flask API, а данные хранятся в SQLite локально или PostgreSQL на хостинге. После сборки сайт и API запускаются на одном адресе.

## Что уже работает

- регистрация ученика и родителя;
- заявка репетитора с подтверждением администратором;
- приглашение наставников и администраторов только через команду проекта;
- вход через защищённую HTTP-only cookie, без хранения токена в браузере;
- настоящие личные чаты: создание диалога, отправка сообщений, непрочитанные сообщения и уведомления;
- создание и проверка занятий, домашние задания, учебные цели, сообщения и уведомления;
- очередь заявок репетиторов в разделе «Заявки» администратора: подтверждение или отклонение;
- адаптивный интерфейс для компьютера и телефона.

## Локальный запуск

Нужны Node.js 20+ и Python 3.10+.

```bash
cd server
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/python app.py
```

Во втором терминале:

```bash
npm install
npm run dev
```

Обычный локальный запуск стартует с пустой базой — вы регистрируете реальные аккаунты сами. Тестовые персонажи появляются только при явном `COGITO_DEMO_DATA=1`; эта переменная нужна автоматическим тестам, а не приложению для людей.

Для проверки серверной части:

```bash
npm run test:api
```

## Публикация без домена

Проект подготовлен для Render: файл `render.yaml` создаёт веб-сервис и PostgreSQL в Frankfurt. После публикации Render выдаст временный публичный адрес вида `https://cogito-light-hearts.onrender.com`.

1. Создайте бесплатные аккаунты на GitHub и Render.
2. В Render выберите **New → Blueprint**, подключите репозиторий и подтвердите ресурсы из `render.yaml`.
3. В окне Blueprint Render попросит два секрета: `ADMIN_EMAIL` и `ADMIN_BOOTSTRAP_PASSWORD`. Укажите свою почту и новый пароль из 12+ символов. Не добавляйте их в GitHub.
4. После завершения сборки откройте выданный адрес и войдите как администратор с этими значениями.

В публичной версии демонстрационные учётные записи и стандартный пароль не создаются. Если пароль администратора не задан, запуск останавливается, а не открывает небезопасный сайт.

Бесплатный Web Service Render может засыпать после 15 минут без посетителей. Важно: бесплатная PostgreSQL у Render удаляется через 30 дней после создания, поэтому этот тариф подходит для проверки и первого показа, но не для постоянной базы с данными пользователей. Для постоянной работы проекта потребуется платная база с резервными копиями. Render поддерживает Flask, Docker и PostgreSQL, а Blueprint связывает сервис с базой автоматически. [Документация Render](https://render.com/docs/free)

## Переменные окружения

| Переменная | Для чего нужна |
| --- | --- |
| `DATABASE_URL` | строка подключения к PostgreSQL; без неё используется локальная SQLite-база |
| `FLASK_ENV=production` | включает защищённую cookie для публичного HTTPS-сайта |
| `ADMIN_EMAIL` | почта первого администратора на новом боевом сайте |
| `ADMIN_BOOTSTRAP_PASSWORD` | секретный пароль первого администратора, минимум 12 символов |
| `PORT` | порт, который задаёт хостинг |

`docker-compose.yml` нужен только для локального запуска с PostgreSQL. Скопируйте `.env.example` в `.env`, укажите свой пароль и запустите `docker compose up --build`.
