# Cogito Light Hearts

Веб-приложение для бесплатных занятий: расписание, задания, чаты и учёт волонтёрских часов. Пять ролей: ученик, родитель, репетитор, наставник и администратор.


## Где находится код

```text
server/
  app.py        запуск сервера и раздача сайта
  accounts.py   регистрация, вход, письма и профиль
  admin.py      доступ администратора, заявки и участники
  study.py      занятия, задания и отчёты
  chat.py       контакты и переписки
  common.py     общие проверки, права и сессии
  database.py   таблицы и подключение к базе
  demo.py       тестовые данные, выключены по умолчанию
src/
  main.js       запуск интерфейса
  router.js     адреса страниц и проверка входа
  Layout.vue    общее меню и шапка
  views/        страницы с формами и кнопками
  stores/       загрузка и хранение данных страниц
  components/   общие кнопки, окна и карточки
  styles/       общее оформление и стили главной
  api.js        запросы к серверу
  config.js     роли и меню
  helpers.js    небольшие расчёты и проверка ссылок
```


В `.vue`-файле `script` содержит действия, `template` — разметку, `style` — оформление. Большие стили главной вынесены в `styles/dashboard.css`. На сервере обычные функции и SQL. Blueprint объединяет обработчики одного файла; `app.py` подключает четыре таких раздела. Других слоёв между запросом и базой нет.


## Запуск без Docker

Нужны Node.js 22.12+ и Python 3.10+. Из корня проекта:

```bash
npm ci
python3 -m venv server/.venv
server/.venv/bin/pip install -r server/requirements.txt
npm run server
```

Во втором терминале: `npm run dev`. Откройте адрес из терминала. В пустой локальной базе первого администратора создают на `/setup-admin`. По умолчанию используется SQLite в `server/data`; тестовые данные включаются только через `COGITO_DEMO_DATA=1`.

## Запуск через Docker

Скопируйте `.env.example` в `.env`, задайте `ADMIN_EMAIL` и `ADMIN_BOOTSTRAP_PASSWORD` (от 12 символов). Затем:

```bash
docker compose up --build
```

Сайт: `http://localhost:5000`. Compose запускает один контейнер приложения. База `cogito.db` и файлы домашних работ сохраняются в томе `cogito_data`, подключённом к `/app/server/data`. Пересоздание контейнера не очищает данные; сам том удалять нельзя без резервной копии.

Автоматического переноса из прежних томов базы нет. Старые тома эта конфигурация не удаляет.

## Проверки

После установки зависимостей запустите `npm run check`: сборка, клиентские тесты, API и все роли. Серверные тесты используют временные базы, не реальные аккаунты. GitHub Actions дополнительно запускает Docker Compose и проверяет сохранность тестовой базы и файла после пересоздания контейнера.

## Аккаунты и публикация

Роль берётся из базы. Администратор назначает роли, блокирует аккаунты и связывает участников в «Участниках». Родитель видит только данные связанного ребёнка. Выход завершает одну сессию; блокировка и смена роли — все сессии участника.

Для входа с разных устройств нужен один HTTPS-адрес с общей базой. На хостинге задайте `APP_URL`, `ADMIN_EMAIL`, `ADMIN_BOOTSTRAP_PASSWORD` и SMTP-настройки из `.env.example`. Используется только SQLite. Если сохранилась старая переменная `DATABASE_URL`, удалите её: приложение сообщит об ошибке, а не переключится незаметно на другую базу. Пароли, `.env` и файлы базы не загружаются в GitHub.


## Amvera

Загрузите проект с `amvera.yaml` и выберите Docker, один экземпляр приложения и регион Москва. Укажите `PORT=5000`, `FLASK_ENV=production`, `APP_URL` с новым HTTPS-адресом.

SQLite хранится в постоянной папке Data, подключённой к `/app/server/data`. При переносе существующей базы её файл `cogito.db` загружают в Data, не в Code и не в Git. Если база пустая, для первого администратора нужны `ADMIN_EMAIL` и секрет `ADMIN_BOOTSTRAP_PASSWORD` от 12 символов. Рабочий сайт уже запущен на Amvera с SQLite и SMTP-письмами подтверждения. Открытие входа на телефоне без VPN и регистрация с письмом подтверждены пользователем.
