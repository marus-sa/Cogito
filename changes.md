# Изменения

### 1. Функциональное требование №1 / Сценарий №1.  
- Вместо логина — подтверждённая почта; служебные роли назначает администратор, репетитора одобряет.
- Причина: проверка почты и защита доступа.

### 2. Функциональные требования №2, №5 / Сценарии №5, №9.  
- Вместо видео и скриншотов — ссылка на диск с записью. Часы подтверждаются по отчётам 
- Причина: не хранить видео и упростить проверку часов.

### 3. Функциональное требование №6 / Сценарий №3 — удалён.  
- Сценарий «Постановка и отслеживание учебных целей ученика» исключён вместе с разделом целей.
- Причина: нет надобности добавлять такую функцию, упрощение проекта

### 4.Сценарий №7.  
- Вместо режимов день/неделя/месяц — список занятий по датам.  
- Причина: упрощение расписания.

### 5. Функциональные требования №1–8 / Инструменты разработки.  
- PostgreSQL, Keycloak, Bootstrap, Nginx и S3 заменены SQLite, сессиями приложения, CSS, Gunicorn и внешними ссылками. Хостинг — Amvera, письма — Gmail SMTP.  
- Причина: меньше сервисов, проще поддержка, упрощение проекта.

### 6. Функциональные требования №1–8 / ТЗ.  
- Нагрузка 300 пользователей не подтверждена; видео хранится вне приложения. Пилот с 10-15 участниками на две недели в процессе 
- Причина: сложность в поиске участников проекта, готовых протестировать продукт
