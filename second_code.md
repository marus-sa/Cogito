# Второй показ кода
## 1. Профиль

Реализованы просмотр и редактирование данных пользователя. 
## 2. Просмотр расписания

Реализован просмотр доступных пользователю занятий. 
## 3. Домашние задания

Реализованы назначение, сдача и проверка работ. 
## 4. Чаты

Реализована личная переписка между доступными участниками. 
## 5. Учёт часов

Реализованы отправка отчёта со ссылкой на видеозапись и проверка наставником или администратором.
